# Interface languages

The header language selector offers **English, Italiano, Русский and Български**. It remains visible while scrolling, including on mobile. English is the default when no preference exists. The choice is saved in this browser under `crisis2action.language`; an optional `?lang=en|it|ru|bg` query sets the initial language of a shared link.

Language changes update the pollution navigator navigation, observation/receptor explanations, institutional and legal checks, guided scenario, task/review controls, statuses, dialogs and Pilot & value content. The retained historical flood module also supports all four languages. Dates and displayed decimal separators follow the selected locale. Source bytes, timestamps, values, units, station IDs, rule/legal IDs and context fingerprints are unchanged. Switching language does not submit a new evaluation, clear an acknowledgement or reset scenario controls.

Original source titles and legal documents retain their original language. Interface descriptions and scenario labels may be translated, while raw evidence JSON, user-entered names/notes and exported incident briefings retain their recorded/original language. A translated-interface notice makes this explicit. The interface translations are not expert-verified legal translations and do not change the review status of any source or interpretation. Drafts continue to contain the original English evidence and caveats.

Implementation: `app/frontend/src/i18n.ts`, `LanguageSwitcher.tsx`, and flat locale JSONs in `app/frontend/src/locales/`. Add or change a user-facing English key consistently in each locale; retain an English fallback for missing entries. The switch uses native language names so it remains identifiable in every language. Storage failures retain a session-only choice.

The report-alignment release extends the four locale catalogs to the new default pollution navigator, dynamic scenario/receptor descriptions, self-reported task statuses, review history and commercial hypotheses. Switching language preserves the selected persistent incident and never submits a task/review mutation. Translated roles remain demo personas; translation cannot verify a legal interpretation.

Historical validation: the earlier flood-language release passed typecheck, lint, build and six browser tests, including all four choices, preference persistence and mobile visibility. Those results belong to that release. Current pollution-release browser checks and publication status are tracked in [VALIDATION](VALIDATION.md); do not infer completion or deployment from earlier language checks. The Italian nine-slide pitch at `/presentation.html` is separate presentation content, not a four-language slide deck.

Changing the interface language does not change Cloudflare Access login policy or the authorized email list. A translation-only change can use the gateway deployment after its required checks. The report-alignment release also changes incident persistence/API behavior and must follow its backend/schema and gateway deployment instructions; its local language changes do not establish that the public app has been updated.
